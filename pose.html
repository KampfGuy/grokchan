How to use
  1. Pick a starting pose under Load.
  2. Choose a body part, then a bone chip (the pink dot shows it on her).
  3. Drag the X / Y / Z sliders, or tap −/+ for 1° nudges. Drag the preview to rotate, pinch or use 🔍 to zoom.
  4. Use finger presets and Mirror left → right / right → left (copies one side onto the other) to save time. Undo steps back.
  5. For a profile picture: pick a camera preset, set the expression, tap ⛶ Fullscreen, frame her and tap ◉ (or use Save picture).
  6. Name it, choose Idle / Talk A / Talk B, then Share (iPhone: send the file to the chat) or Download.
